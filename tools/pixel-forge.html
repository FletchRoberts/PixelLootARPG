Pixel Forge

Seeded procedural pixel art: monsters, heroes, loot, currency and tiles. Same seed, same sprite, every time.

Click any sprite to download it as a PNG at the export scale. "Download sheet" saves a spritesheet PNG plus a JSON atlas in Phaser's JSON-hash format (load with this.load.atlas(key, png, json)).

URL parameters

pixel-forge.html?type=monster&theme=poison&size=32&seed=act1&count=16&scale=1

Scripting API (for Claude Code / headless browser)

PixelGen.types   // ['monster','hero','weapon','potion','currency','ring','floor','wall']
PixelGen.themes  // ['random','fire','ice','poison','shadow','gold','earth','blood','arcane']
const g = PixelGen.generate({type:'potion', seed:'hp-1', size:32, theme:'blood'})
PixelGen.toCanvas(g, 4).toDataURL()           // single sprite PNG
const {canvas, atlas} = PixelGen.sheet({type:'monster', seed:'z1', size:32, theme:'fire', count:16, scale:1})
canvas.toDataURL(); JSON.stringify(atlas)     // spritesheet + atlas

The generator core is plain JavaScript with no dependencies (only toCanvas/sheet touch the DOM), so it can also be copied into the game to create sprites at runtime.
